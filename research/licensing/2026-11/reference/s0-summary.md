## Summary

This is ATR's working reference for reptile and frog keeping licences in each Australian state and territory. Each jurisdiction section has a field table with the authority's own licence names, costs, waits and rules. Every fact links to the page it came from and the date it was checked. Anything marked **unconfirmed** could not be found on an official page and must not go into app copy until someone verifies it. Species class or schedule codes appear only in the boxes labelled "Authority's internal categories". They are for Rowan's reference and must never be shown in the app. Check the app's `states.js` and licence grids against the "What this means for the app" note at the end of each section.

**Last fully checked: 8 Nov 2026.** A scheduled check runs monthly. When a fact changes, update the section, add a row to the change log and update the app.
